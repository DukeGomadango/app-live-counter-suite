# スロット用効果音

このフォルダに以下のファイルを配置すると、スロットで効果音が再生されます。

| ファイル名 | 用途 |
|-----------|------|
| `spin.mp3` | リール回転中（ループ用。任意。なければ再生されません） |
| `stop.mp3` | 各リールをストップしたとき |
| `reach.mp3` | リーチ表示時（左・中が揃い右リールを回しているとき。任意） |
| `win.mp3` | 役成立時（小役・ボーナス・リプレイ共通） |

ファイルが存在しない場合は再生されません。設定パネルの「SEを再生する」でオン/オフを切り替えられます。
