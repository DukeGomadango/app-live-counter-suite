# スロット機能実装計画（目押しB方式・パチスロ仕様反映版）

## 概要

目押し（B: 止めるたびに抽選）を採用し、パチスロの用語・ルール・演出を**すべて本実装**として取り込む。以下はオプションにせず標準仕様として実装する。

- **順押し**: 左→中→右の順でしか止められない（常時適用）
- **理論機械割**: 常に画面に表示
- **天井**: 機能として常に実装（回転数0で無効）
- **リプレイ**: 役の一種として常に実装
- **役の種類（ボーナス／小役／リプレイ／チャンス目）**: 図柄に必ず持たせる
- **リール別図柄配列**: 各リールごとに別配列を編集可能（デフォルトから用意）
- **設定プリセット・用語（枚・役・設定）**: UI・ヘルプで統一

リール数変更・プレイヤー別BET・確率設定・図柄カスタム・ストップボタン・リーチ演出まで含め、上記を標準仕様とする。

---

## 1. 用語とルール（パチスロ準拠・全反映）

- **役**: リールの停止結果で成立する組み合わせ。全リール同一図柄＝1役として扱う。
- **ストップ / 出目**: 各リールに止まった図柄（止まった目）。
- **枚**: 配当の単位。BET も「○枚」で表示・入力する。
- **設定**: 確率のプリセット。設定A（甘め）・設定B（標準）・設定C（辛め）など、重みのプリセット名として採用する。
- **順押し**: 左リール → 中リール → 右リールの順でしか止められない。**常にこのルールで固定**（オプションにしない）。変則押しは不可。
- **機械割**: 理論上の回収率（％）。現在の図柄確率・配当から計算し、**常に画面に表示**する。
- **役の種類**: 図柄に「ボーナス」「小役」「チャンス目」などの種別ラベルを持たせ、一覧・ヘルプで説明する。リプレイは「当選時BET消費なしで1回転」として本実装する。

---

## 2. データ・型定義（[src/lib/slot.ts](src/lib/slot.ts) 新規）

### 2.1 図柄・役

- **SlotSymbol**: `id`, `label`（表示）, `weight`（重み）, `payoutMultiplier`（役成立時の倍率。枚＝BET×倍率）, `role`: `"bonus" | "small" | "replay" | "chance"`（役の種類）
- **リプレイ**: `role === "replay"` の図柄で役成立時は、配当に加え「次の1回転はBETを消費しない」を付与する。
- **リール配列**: 各リールごとに**別の図柄リスト（並び）**を持つ。`reelStrips: SlotSymbol[][]`（`reelStrips[i]` が i 番目リールの配列）。図柄の種類は共通でも、並び・出現順はリールごとに設定可能。

### 2.2 プレイヤー・BET

- **SlotPlayer**: `id`, `name`, `balance`（残高・枚）, `defaultBet`（1回あたりのBET枚数）
- スピン開始時に `balance` から `defaultBet` を控除。役成立時は配当（枚）を加算。リプレイ成立時は当該回のBETを戻す＋次の1回はBET控除しない。

### 2.3 設定・天井

- **SlotSettings**: `reelCount`（2〜5 または 2〜7）, `accentColor`, `orbIntensity`, `soundEnabled`, **設定プリセット名**（表示用）, **天井**
- **天井**: `ceilingSpins: number`（この回転数消化で高配当役を1回確定。0のときは天井なし）。**常に実装**（オプションにしない）。天井到達時は次回スピンで「ボーナス役」を1つ強制成立させる（または専用フラグで次回のみ抽選を上書き）。

### 2.4 抽選・役判定

- **pickSymbolByWeight(symbols: SlotSymbol[]): number**  
  重み付き乱数でインデックスを返す。各リールの **reelStrips[reelIndex]** に対して、停止タイミングで1回だけ呼ぶ（目押しB）。
- **止める順番**: 必ず左(0) → 中(1) → 右(2) の順。`nextStoppableReelIndex` のような状態で「今止めていいリール」を管理し、それ以外のストップボタンは無効または非表示。
- **checkWin(reelResults: number[], reelStrips: SlotSymbol[][]): { win: boolean; symbolIndex: number | null; multiplier: number; isReplay: boolean }**  
  全リール同じ役（図柄IDで判定）ならその図柄の倍率とリプレイ可否を返す。
- **理論機械割**: 全図柄の出現確率（重み／合計）と配当倍率から期待値を計算し、`(期待払い戻し／BET)×100` を常に表示する。設定パネルまたはメイン画面の固定表示。

## 3. UI・画面構成

### 3.1 メインエリア

- **リール**: `reelCount` 個を横並び。各リールは **SlotReel** コンポーネントで、**そのリール用の reelStrips[i]** を表示。
- **ストップボタン**: 左から順にしか押せない。現在止められるリールだけ有効、他は無効またはグレーアウト。押した瞬間にそのリールで `pickSymbolByWeight(reelStrips[i])` を実行し、結果のインデックスでアニメーション停止。
- **スピン**: 全リールを回転開始。天井カウントを1増やす。天井に達していたら次回はボーナス確定処理。
- **順押しの明示**: 「左→中→右の順に止めてください」を短く表示するか、現在止められるリールをハイライトして示す。

### 3.2 リールコンポーネント（[src/components/slot/SlotReel.tsx](src/components/slot/SlotReel.tsx)）

- **props**: `symbols: SlotSymbol[]`（そのリールの配列）, `isSpinning: boolean`, `onStop: () => void`, `stoppedIndex: number | null`, `canStop: boolean`（順押しで今このリールを止めてよいか）
- 縦方向に図柄を並べ、回転中はループスクロール。`onStop` は親が「このリールを止める」と決めたときに呼び、親が `pickSymbolByWeight` で結果を決めて `stoppedIndex` を渡す。`canStop === false` のときはストップボタンを無効化。
- **リーチ演出**: 左・中が揃い「あと1つ」の状態で右リールを回している間、リーチ表示（点滅・SE）を行う。役成立時はフラッシュ／払い出し枚数表示。

### 3.3 設定・図柄・プレイヤー

- **設定パネル**: リール数、テーマ（アクセント・オーブ・SE）、**設定プリセット**（確率プリセットの選択）、**理論機械割の表示**、**天井までの回転数**（0で天井なし。常に実装）。
- **リール別図柄配列**: 各リールごとに「このリールの並び」を編集できるUI。共通の図柄マスタから選んで並べる、またはリールごとに図柄リストを編集する。デフォルトは3リール分の配列を用意（例: 左は7少なめ、右はベル多めなど）。
- **プレイヤー**: 追加・名前・残高・BET枚数。プレイヤー選択で「誰が打つか」を切り替え。BETは「○枚」で統一表示。

## 3.5 見た目・演出（射幸性・スロット感・実現可能性）

Webアプリでのスロット見た目実装のリサーチに基づき、射幸性・スロット感・実現可能性を満たす演出を**本実装**として以下に定める。既存のルーレット（SPIN_EASE、RouletteHitEffect）・ガチャ（パーティクル・フェーズ）・useGlassStyle を流用する。

### リールの見た目

| 要素 | 仕様 | 備考 |
|------|------|------|
| **リール窓** | 1リール＝縦長の枠。`overflow: hidden`。上・下に `box-shadow: inset` で暗い影を入れ、枠の奥行き感を出す。枠はガラス風（useGlassStyle）または細い枠線。 | 実機の窓に近づけつつ、既存世界観と統一。 |
| **図柄の並び** | 各リールは縦に図柄を並べた1本のストリップ。同じ並びを上下に繰り返して `translateY` でループし、無限スクロールに見せる。停止時は「止まった図柄が窓中央」になるよう `translateY` を ease-out で止める。 | 図柄はテキストまたは絵文字で十分。画像は拡張で対応可。 |
| **回転中** | 一定速度の縦スクロール（linear）。Framer Motion の `animate` または CSS keyframes で実装。 | 回っている間の「まだ分からない」感を維持。 |
| **停止時** | 止まる瞬間のみ **ease-out**。既存 [RouletteWheel.tsx](src/components/roulette/RouletteWheel.tsx) の `SPIN_EASE = [0.1, 0.78, 0.62, 0.98]` を流用（前半で進み・後半でじりじり減速）。0.3〜0.6秒程度で「スッ」と減速して止める。 | 実機の減速停止に近い動き。 |
| **実装** | ストップ押下時に結果インデックスが決まったら、そのインデックスに対応する `translateY` を計算し、`motion.div` の `animate={{ y: targetY }}` に `transition: { duration: 0.4, ease: SPIN_EASE }` を指定。 | DOM + Framer Motion で完結。WebGL は不要。 |

### 順押しの見た目

| 要素 | 仕様 | 備考 |
|------|------|------|
| **止められるリール** | 次に止めていいリール（左から順）だけ枠をハイライト（アクセント色の枠・弱い発光）。それ以外はやや暗くするか枠を通常色に。 | 「次はここを止める」が一目で分かり、操作がゲームっぽくなる。 |
| **ストップボタン** | 各リールの下に「ストップ」ボタン。押せるリールだけ有効、他は disabled でグレー。 | `nextStoppableReelIndex` と連携。 |
| **順序の明示** | 「左のリールから順に止めてください」を短く表示するか、アイコン（1→2→3）で順序を示す。 | パチスロの順押しルールを視覚化。 |

### リーチ・当たりの演出

| 要素 | 仕様 | 備考 |
|------|------|------|
| **リーチ状態** | 左・中が同じ図柄で揃い、右だけ回っている間を「リーチ」とする。この間だけ右リール周りをアクセント色で点滅またはゆっくり明滅（border / box-shadow）。必要なら「REACH」や「リーチ」の短いラベルを表示。 | 実機のリーチ灯に相当。当たりに「近づいた」感で期待感を上げる。 |
| **役成立時** | 3つ揃った瞬間に (1) リール枠または背景を一瞬フラッシュ（白またはアクセント色）、(2) 役名＋払い出し枚数（例: 「スイカ 15枚」）を中央に表示、(3) 短いSE。数秒で非表示。 | [RouletteHitEffect.tsx](src/components/roulette/RouletteHitEffect.tsx) と同様のオーバーレイ＋テキストで実装。 |
| **リプレイ時** | 「REPLAY」と短く表示。色を変える（例: ゴールド）ことでボーナスと区別。 | リプレイ告知のフィードバック。 |
| **紙吹雪** | ボーナス役や高配当役のときだけ、既存 RouletteHitEffect のような紙吹雪を出す。小役のみのときは出さないか控えめに。 | 大当たりの特別感。RouletteHitEffect を流用し、役種で ON/OFF または量を変える。 |

### 全体レイアウト・世界観

| 要素 | 仕様 | 備考 |
|------|------|------|
| **背景** | ルーレット・ガチャと同様のオーブ背景＋ガラス風パネル。スロットメインは中央にまとめ、左右にサイドバー（設定・図柄・プレイヤー）。 | 既存 RouletteContent / GachaContent のレイアウトを流用。 |
| **アクセント色** | 設定で選んだ `accentColor` を、リール枠のハイライト・リーチの光・当たりフラッシュ・ボタンに統一。 | 実機のランプ色に相当。 |
| **機械割表示** | 設定パネルまたはメイン上部に「理論機械割 ○○%」を常時表示。数字だけのコンパクトな表示。 | 射幸性を「仕組み」として伝える。 |
| **枚数・BET** | 「BET 3枚」「払い出し 15枚」など単位を「枚」で統一。プレイヤー残高も「○○枚」と表示。 | 実機の枚表示に合わせる。 |

### 演出の実装優先度

- **必須（初回リリース）**: リール窓＋縦ループ＋ease-out 停止、順押しのハイライトとストップボタン、役成立時のフラッシュ＋役名・枚数表示、リプレイ表示、世界観（オーブ・ガラス・アクセント色・枚表示）。
- **推奨**: リーチ時の右リール周りの点滅／「REACH」表示、高配当時の紙吹雪（RouletteHitEffect 流用）、理論機械割の表示。
- **余裕があれば**: 図柄を画像にする、ストップ音・リーチ音・当たり音の差別化、大当たり時だけ長めのフラッシュや専用SE。

## 4. 天井の本実装

- **ceilingSpins**: スピンするたびにカウントを加算。リプレイでBETなし回転した場合も「消化」としてカウントする（実機に近い）。
- **ceilingReached**: カウントが `ceilingSpins` に達したらフラグを立て、次回スピンで「ボーナス役」を1つ確定させる（全リールに同じボーナス図柄を出させる）。確定後はカウントをリセット。
- 画面上に「天井まで ○○回」のような表示を出し、ユーザーが把握できるようにする。

---

## 5. リプレイの本実装

- 役判定で `isReplay === true` の場合:
  - その回のBETをプレイヤーに戻す（控除しない扱い）。
  - 「次の1回はBET控除なし」フラグを立て、次のスピンでは `balance` を減らさずに回す。1回消化したらフラグを解除。
- リプレイ成立時は「REPLAY」などの表示と短いSEでフィードバックする。

## 7. 実装順序

1. **lib/slot.ts**: 型・reelStrips・pickSymbolByWeight・checkWin・機械割計算・天井・リプレイロジック。
2. **app/slot**: layout, page, SlotContent の骨組み。順押し（nextStoppableReelIndex）とストップ時の抽選を実装。
3. **SlotReel.tsx**: リール表示・回転／停止アニメ・canStop によるボタン無効化。見た目は **3.5** に従う（窓・inset 影・縦ループ・SPIN_EASE で停止・順押しハイライト）。
4. **天井**: カウント・到達判定・次回ボーナス確定。画面に「天井まで ○○回」表示。
5. **リプレイ**: 役判定の isReplay、BET戻し・次回BETなしフラグ。REPLAY表示・SE。
6. **理論機械割**: 計算関数と常時表示エリア。
7. **リール別配列**: 設定UIで reelStrips をリールごとに編集。デフォルトは3本分の配列を用意。
8. **設定プリセット・役の種類**: 図柄の role、設定名の表示。設定プリセットは重みのプリセットとして保存・読み込み。
9. **プレイヤー・BET**: 残高・BET枚数・枚表示の統一。
10. **リーチ・当たり演出**: **3.5** に従い、左・中揃い時の右リール周り点滅／「REACH」表示、役成立時のフラッシュ＋役名・枚数表示、リプレイ表示、高配当時の紙吹雪（RouletteHitEffect 流用）。
11. **ヘルプ・JsonLd・changelog・Split・HelpButton**: 用語と機能を反映した文言で同期。

## 8. 注意事項

- **実機との違い**: ヘルプに「実機のパチスロとは仕様が異なります」「止めるタイミングで結果が変わる仕様です」と明記する。
- **役は1ライン**: 初版は「全リール同一図柄」のみ。複数ラインや「2つ揃い」は拡張で検討。
- **SE**: スピン・ストップ・リーチ・役成立・リプレイ用の音声を用意する。ルーレット同様 `/sounds/slot/` を想定。
